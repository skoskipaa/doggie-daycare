# Doggie Daycare

A dog walking and daycare reservation service built with Next.js (App Router), React, TypeScript, and Tailwind CSS.

@AGENTS.md

## Product spec

The product specification lives in @SPEC.md. Follow it when implementing features.

## Commands

- `npm run dev` — start the dev server at http://localhost:3000
- `npm run build` — production build
- `npm run lint` — run ESLint
